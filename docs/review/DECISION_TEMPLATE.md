## 消费状态

> 决策文档的生命周期账本：落盘 ≠ 可采纳。评审逐行回查锚点表并全部置 ☒ 后，
> 状态从「未评审」流转为「已评审」；开放决策点经用户拍板后为「已裁决」。

| 项 | 值 |
|------|------|
| 落盘日期 | {YYYY-MM-DD} |
| 评审状态 | 未评审 |
| 评审记录 | —（评审后填：报告链接或核对结论，含证伪项） |
| 裁决记录 | —（拍板后填：各开放决策点的结论） |
