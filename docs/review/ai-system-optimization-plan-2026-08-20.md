## 3. 核心论证：歼灭律

**定律**：本系统历史中，每一类缺陷的消灭都遵循"review 发现 → 模式入库 → 机械防线下沉 → 该类归零"，无一例外；当前未归零的类恰是未完成下沉的类（姊妹类、文档类残余形态）。

**对抗检验**（混淆假设：归零是存量自然耗尽而非防线之功）：三层证据支持因果方向——方言类防线建立前后产出突变；姊妹类同域同期无防线而持续产出（自然对照：若自然耗尽成立，姊妹类无理由不停）；断言红测证明检测机制有效。定级 [推断]（准实验，每类一例，无随机化）。

**归因判据**（失败信号可归因的关键）：姊妹防线建成两轮后若复发——复发项在联动清单覆盖面内 = 执行失败（补清单）；在面外 = 歼灭律对该类不成立的证据（另谋手段）。

**适用域边界**：歼灭律前提是根因类有限可枚举且域稳定。开拓域（新 Broker、新业务子域）会批量产生新类，系统回到密集发现期属设计内行为。"不收敛焦虑"的完整解构：稳定域高危残差（实际已收敛）+ P2/P3 与优化类残差（目标函数开放，不收敛是本性）+ 开拓期密集产出（正常）——三者账本口径可分，感知口径混同。

**维持现状的机会成本**：姊妹类至今累计产出至少 12+ 个 P1/P2，每个的全成本 = 一轮全量 review 摊销 + 修复 + 回归测试 + 验证轮复核；且无自然停机证据（软防线三重覆盖跨多轮失效），是永续支出流。对比一次性歼灭投入 + 低额红测维护。

**失效机制**（防线为什么放修复端）：修复 agent 的工作单位是任务/文件，族信息不在其上下文；review 端 checklist 有效所以总能发现，修复端无联动所以总在漏。主防线放产生侧，但用确定性手段（机械清单），不是概率注入。
**独有检出面**：均匀缺失型（四家全无守卫，如 leaseDuration 非负四家均匀缺口）——单文件逐行原理上不可见，只有横向并列能看见。

## 9. 全局度量与终态判据

**度量（零新增，复用五指标）**：姊妹类复发率 → 0 并持续；方言类零复发持续；文档类 P3 下降；逃逸率保持 0；review 轮次时长下降。

**终态判据**：review 收缩到真语义残差 + 均匀缺失检出面，"过筛子不收敛"在账本口径可验证消失。**反指标**：若 review 收缩同时逃逸率上升 = 收缩过早，回退一档。

## 10. 否决项记录（含重启条件）

| 项 | 内容 | 否决理由 | 重启条件 |
|---|---|---|---|
| A：事前疫苗 | 把问题卡/逃逸账本注入写码端上下文 | ①概率层注入，违反"确定性优先于概率性"元规则；②拦住了什么永远是反事实，不可红测（V16/#13 文化下是异类）；③残余缺陷成因分布不支持（姊妹类是遗漏型、方言类是验证盲区型，注入知识对两者无效，当前 P1 中无无知型） | 新 agent 上手或新域模式下，无知型错误在账本中回升 |
| E：修复候选排序（LLM-as-a-Verifier 集成） | P0/P1 修复生成 N 候选，连续分数 pairwise 排序选优 | 激活条件（逃逸账本出现修复缺陷逃逸）全程未发生；更便宜的确定性手段（带回归测试的修复纪律）已把修复自带缺陷率压到 0 | 逃逸账本出现"修复缺陷逃逸到 CI/生产"条目时，按回测门重启（历史对照对命中率 ≥70% 试点、<60% 关闭） |

**论文最终定位**：LLM-as-a-Verifier 解决候选选择（best-of-N），非缺陷穷尽发现，与本项目核心痛点错位；保留价值为方法论表述（验证强度内生且可分层）与 E 的条件触发器。

**群聊三方观点定位**：机械门禁方向（rico）正确，死因在防线形态与生长方式（预先浇筑静态基建 vs 从逃逸记录生长）；上一级门禁主张（北葵）是正确战略判断，落地为 T2 的 CI 固化与强度分层；事前避免诉求（sky）的确定性形态已存在（教训库/问题卡/误判库），T1 把防线放修复任务分解处即"事前"的确定性版本。

## 11. 纪律性约束（执行期间持续生效）

1. 一切新增门禁/检查项**先红测后转正**（V16/#13 前科，不可豁免）
2. 脚本改动**三方同步**（脚本 ↔ prompt ↔ conventions），verify-ai-system 保持全绿
3. 账本只增不删、报告不可变等既有 11 条维护规则不因本方案放松
4. 观察态必须带 owner 和期限，禁止永久 audit-only
5. 本文失败信号预注册表（§8）随执行进度在复核点逐条对照，结果追加至文末「执行记录」

## 12. 认识论声明

- **[事实] 级**：收敛曲线、姊妹类持续与漏点定位、零逃逸、五个歼灭先例、P3 构成、no-op 前科、账本磨损。
- **[推断] 级**：歼灭律因果方向（准实验）、姊妹联动判据完备性、文档类下沉收益幅度、终态推演。
- **三项剩余不确定性**（只有执行能消解）：管线孪生种子表覆盖度；P1 收敛判断的样本长度（近五轮）；文档机械化的形态边界。
