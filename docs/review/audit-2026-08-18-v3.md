## 8. 反驳结果

- Kafka offset 候选降级：源码已明确 at-most-once，不是未声明回归；是否升级为 at-least-once由产品裁决。
- HITL 超时候选降级：Store 契约只扫描 Active，无 deadline 可以是合法人工审批策略；需显式需求后再改。
- Idempotency serializeResult 原始链路更正：异常不会进入外层 MarkFailed，但会返回 Executed 且留下 Processing，租约到期后仍可能重放。
- Activity flaky：10 次 Integration 重跑均通过，本轮未复现；保留在测试隔离债务，不作为已确认 P1。
- 负向声明边界：gitleaks 不可用，手工模式扫描存在误报，不能声明“历史无秘密”。
