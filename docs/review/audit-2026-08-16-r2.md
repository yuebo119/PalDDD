## 三、P1 定稿（4 项，全部探针/机械实证）

### F-01 · EventLogDbContext PG 唯一冲突重查踩 aborted 事务（25P02 替换原始异常）· P1 ✅
- **触发路径**：PG + 显式事务内并发 `AppendAsync` → SaveChanges 抛 23505 → catch 内 `GetActualStreamVersionAsync` 在同一 aborted 事务重查 → 25P02 替换原 DbUpdateException，`EventStreamConcurrencyException` 重试契约失效。
- **证据**：代码亲验（EventLogDbContext.cs:213-233 无守卫）；姊妹 Dapper（DapperEventLog.cs:128-142）/PalORM（PalOrmEventLog.cs:119-134）均有"重查失败保守上抛原始异常"守卫。**探针实锤**：真实 PG 显式事务 23505 后同事务 SELECT → 25P02。
- **涉及**：src/PalDDD.EventLog.EFCore/EventLogDbContext.cs

### F-02 · PalOrmSagaStateStore PG 路径 saga_data 字符串直写 jsonb（42804）· P1 ✅
- **触发路径**：TProvider=PG 且 `_jsonTypeInfo` 非 null 时 SaveChangesAsync → `JsonSerializer.Serialize` 产出 string 参数直写 jsonb 列 → 42804（PD23 同族）。
- **证据**：代码亲验（PalOrmSagaStateStore.cs:127/137/154 无 CAST/原生 jsonb）；Dapper 姊妹有 `CAST(@data AS jsonb)`（SqlTemplates）。**探针实锤**：Npgsql text 参数 INSERT jsonb 列 → 42804。既有方言探针 40/40 全绿是因为其 Saga 用例 `_jsonTypeInfo=null` 路径，未覆盖本缺陷。
- **涉及**：src/PalDDD.PalORM/Stores/PalOrmSagaStateStore.cs

### F-03 · PalDDD.slnx 缺失两个公开发布元包（Base/Extension）· P1 ✅
- **触发路径**：`dotnet build/test/pack PalDDD.slnx` 与 CI 永不编译两个元包——包内容损坏/依赖断裂照常发布，release 完整性缺口。
- **证据**：src 36 个 csproj 实存 Base/Extension；`dotnet sln PalDDD.slnx list` 0 命中；slnx 56 个 Project Path = 34 src（缺 2）。
- **涉及**：PalDDD.slnx（+ Base/Extension csproj 私有版本引用迁 CPM）

### F-04 · scripts/publish-main.sh 强制覆盖 origin/main，违反仓库红线 · P1 ✅
- **触发路径**：执行 `bash scripts/publish-main.sh` → orphan 分支 `git push --force` 到 main，覆盖 release 分支历史；branch-flow.md:35 明确禁止、release.md:226 禁止 AI/自动化自主合并 main。
- **证据**：脚本第 10 行实读；两份规范实读；无任何豁免声明。
- **涉及**：scripts/publish-main.sh、docs/branch-flow.md、docs/release.md
