**自反驳（≥3 条，辩证步骤 1-4）**：

1. 「B1 先 `--update` 基线绿了再说」→ 否。8 条里含死属性（IsSettled）与空 catch，update 即把真缺陷洗白成基线，门禁退化为装饰（门禁两轴：执行过吗 / 拒绝过吗）。必须修不 update。

3. 「B3 catch 内 await RejectAsync 会死锁」→ 已排除。handler 在 worker 线程（channel 消费侧），确认命令由独立消费线程应用（KafkaBroker.cs:493-549 结构 + :930 注释「消费线程 poll 超时 100ms 内必定回到队列」）；关停窗口 completion 被放弃走 OCE 分支，语义正确。
