## 1. 定位：三个平面，一套体系

三份来源各自回答了质量价值链上不同位置的问题，融合后构成完整覆盖：

```
统一原则（四源收敛）
│
├── 生成平面 [SYNTHESIS 主导]      事前：规格锚定 → 上下文纪律 → 有界生成
├── 检测修复平面 [优化方案主导]     事中事后：歼灭姊妹类 → 实测固化 → 文档下沉
└── 系统平面 [控制论主导]           元层：传感器定标台账 → 翻转检测 → 修复门 → 适应分层
        ↑ 三平面共用一个度量地基（Phase 0）与一套预注册退役制度
```

## 2. 统一原则与强推论（论证基石，含证伪结构）

**统一原则（弱版本）**：质量知识只应以可机械执行的形式存在；概率层是出生地，确定性层是唯一归宿。四源独立收敛：本仓歼灭律五先例（实证）、控制论 D3 执行器位置原理（理论）、SYNTHESIS 原则 2 确定性约束 > 概率恳求（文献）、全局 AGENTS.md 元规则"确定性 > 概率性"（既有约定）。

**强推论（仅本仓实证支撑）**：缺陷类在机械防线下沉后归零（歼灭律，五先例，准实验定级）。**证伪结构**：姊妹防线若未使姊妹类归零，证伪的是强推论对该类的适用性（按归因判据分流面内/面外），不证伪统一原则，体系不推倒。

**适应规则**（= 优化方案 B2 = 控制论 D5，两独立设计同一机制）：单事件只进观察区；同类复发 ≥2 强制下沉或书面豁免。

**Model C 手检结论**：e(k+1)=(1-s)e(k)+p'a(k) 在"对在场全部错误尝试修复"读法下 s>p' 收敛条件数学成立，但结论脆度依赖模型解释。**协议采纳，定理不当教条**——操作价值在修复门两问本身。
