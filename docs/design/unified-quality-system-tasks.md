> 任务编号沿用方案相位号（0a、1a…），子步骤加小数（0a.1…）。

## 执行纪律（全程生效）

1. **红测先行**：一切新增门禁/检查项，先以已知坏输入验证会红，再转正（V16/#13 前科，不可豁免）
2. **三方同步**：脚本 ↔ prompt ↔ conventions；verify-ai-system 保持全绿
3. **双仓提交**：`.ai/` 内改动提交 .ai 仓库；`docs/`、`.github/` 提交主仓；两仓各自维护、不相互调用
4. **只增不删**：本清单状态更新只追加（完成日期 + commit hash + 红测记录指针），不改写已定条目
5. **失败信号**：任何组件触发 `unified-quality-system.md` §8 预注册表即按处置执行，不加码
