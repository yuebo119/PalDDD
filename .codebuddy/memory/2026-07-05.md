## Pal.DDD Serena 符号级架构评审（REVIEW-2026-07-05）

**报告**：`docs/review/review-2026-07-05-serena.md`
**方法**：Serena LSP 语义分析 + find_symbol 符号体提取 + 架构边界交叉验证
**综合评分**：**8.6/10** · 审计意见：**推荐采用**

### Serena 分析的核心符号（13 个完整 body 提取）
- Entity/Entity<TId>：单链表事件收集 O(1) 追加 + ref struct 枚举器 + 值相等性语义
- DomainEvent：AsyncLocal<TimeProvider> 而非 DI，5 点设计决策论证
- SmartEnum：FrozenDictionary + Interlocked.CompareExchange + Volatile.Read + 源码生成器注册
- Dispatcher：FrozenDictionary + double-check lock 冻结 + ValueTask IsCompletedSuccessfully 快速路径
- PipelineStateMachine：零闭包状态机 ~40B/请求，替代闭包链（原 ~72B/行为 + ~40B LINQ）
- OutboxMessage：租约锁字段完备（LockedBy/LockedUntil/RetryCount/NextAttemptAt）
- OutboxBatchProcessor：批次原子时间戳 + 逐条持久化 + 原子计数递增 + at-least-once 诚实声明
- RecordedEvent：双构造路径，RehydrateFromBytes 零拷贝引用赋值
- IEventLog：命名流 + ExpectedStreamVersion 乐观并发 + 全局单调递增位置
- DapperUnitOfWork：共享 DbTransaction + SaveChanges 幂等 no-op + DisposeAsync 防泄漏
- DapperBulkCopy：三方言最优（PG COPY/MySQL BulkCopy+Warnings/SQLite 事务+参数复用）+ switch 编译时分发
- MessageBrokerBase：模板方法三级重载，子类仅需实现传输核心

### 三大核心优势
1. **DDD 战术模式完整落地**：Entity/AggregateRoot/DomainEvent/ValueObject/SmartEnum/Specification/Saga/EventLog/Projection 全覆盖，无过度抽象
2. **AOT 作为一等公民**：DIM 桥接消除反射、源码生成器注册、FrozenDictionary 替代字典、非 AOT 项目三属性透明化
3. **性能契约工程化**：零分配快速路径、零闭包管道、零拷贝读取、ref struct 枚举器

### Serena 工具使用要点
- `get_symbols_overview` 需要文件路径而非目录路径
- `find_symbol` 用 `name_path_pattern`（不带前导斜杠），`relative_path` 限定文件
- 泛型类符号（如 Saga<TState>）find_symbol 可能返回空，改用 search_for_pattern
- 大文件（Saga.cs 34KB）find_symbol 可能超限，用 depth=0 或 search_for_pattern 替代
